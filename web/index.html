What counts for this field

Untick a source or a gauge and it stops counting for this field, in the past as well as going forward. Nothing is deleted — tick it back on and the history returns.

The list is the nearest six gauges, and the nearest two count to begin with. Unticking one does not promote another: a gauge half a mile away and one thirty miles away are measurements of different ground, and swapping one for the other would quietly change what this field's number means. The rest are listed so you can add one deliberately.

Data collection

This keeps itself up to date while the dashboard is running — it checks every 15 minutes and pulls whenever the record has gone stale, including catching up after the computer has been off. Nothing here needs a command prompt.



    

      
      
      
    

    

  


  

    

      

        
Export & import

        
Move a date range between machines. Run this on more than one computer and their gaps will not line up — RFC QPE publishes no archive, so a day missed while a machine was off is gone on that machine but not on the one that was awake. Importing never overwrites newer data, and re-importing the same file changes nothing.

Backup & restore

        
Everything in one file: your settings, fields, manual gauges, weather station and the whole rainfall database. This is how you set a second computer up as a copy of this one, or move to a new machine — download it here, restore it there.

        
Restoring replaces everything on this machine. It is not a merge — use Export & import above for two machines that are both already collecting. A copy of what is here now is saved to data/backups first, so a restore onto the wrong machine can be undone.

Your own weather station

        
A Davis — or anything else publishing WeatherLink's NOAA-format reports: NOAAMO.txt for the current month's daily rows, NOAAYR.txt for the year's monthly totals. It stands on your own ground, so it ranks first for whichever fields are nearest and becomes the reference the radar is checked against.

        
Give it the folder the two reports sit in and both are found — or either file, and the other one is found beside it. Both matter and they do different jobs: the daily report is the only source of daily on-farm rainfall and is overwritten every month, while the yearly one is what the calibration below is measured from.

        
Use the station's coordinates, not a field's. Test the address and it reads them out of the report header for you. You can also paste a latitude, longitude pair into either box and both fill in.

      

    

    


    

      
      
      
      
      
      
      
      
      
      
      
    

    

  


  

    

      

        
Manual gauges

        
Gauges you read yourself — the stick by the weather station, a neighbour's gauge near a field. Nothing fetches these, so they are never overwritten by an ingest. They rank by distance like any other gauge and are charted as their own series, so they stay an independent check rather than getting averaged into the automatic number. Paste a latitude, longitude pair into either coordinate box and both fill in.

      

    

    


    

      
      
      
      
      
    


    

      
      
      
      
    

    

    

  


  

    

      

        
Fields

        
Acres and farm save as soon as you leave the box. Adding or moving a field maps its nearby gauges and pulls its history automatically — watch it happen under Data collection above. Paste a latitude, longitude pair straight out of a map into either coordinate box and both fill in.

      

    

    

    

    

      
      
      
      
      
      
    

    

  


  

    

      

        
Software updates

        
Checked once a day against where this copy was installed from. Updating downloads the new code and restarts the dashboard; your fields, settings and rainfall history are untouched. It will refuse rather than overwrite local changes.
